# Налаштування безкоштовної AI-перевірки та генерації практики (Gemini API)

У SwiftLab інтегровано автоматичну перевірку Swift-коду та генерацію додаткових практичних задач через серверну частину Next.js (`src/app/api/check-challenge` та `src/app/api/generate-practice`).

## 1. Отримання безкоштовного ключа Gemini API

1. Перейдіть до [Google AI Studio](https://aistudio.google.com/).
2. Створіть API-ключ у новому або наявному проєкті **без прив'язки платного білінгу (Cloud Billing)** — це гарантує роботу в межах безкоштовного тарифу **Gemini Developer API Free Tier** без ризику випадкового списання коштів.
3. Скопіюйте ключ у файл `.env.local` (для локальної розробки) або в змінні середовища вашого хостингу (Vercel / Railway / Render / VPS):

```env
GEMINI_API_KEY=ваш_ключ_з_ai_studio
```

> **Безпека:** змінна `GEMINI_API_KEY` не має префікса `NEXT_PUBLIC_`, тому ключ ніколи не потрапляє в браузер користувача.

## 2. Додаткові змінні середовища (опціонально)

```env
# Основна та резервна моделі Free Tier
GEMINI_MODEL=gemini-3.8-flash
GEMINI_FALLBACK_MODEL=gemini-3.1-flash-lite

# Денні ліміти AI-перевірок на користувача (UTC доба)
AI_DAILY_LIMIT_STUDENT=15
AI_DAILY_LIMIT_ADMIN=100

# Окремий секрет для HMAC-підпису AI-генерованих задач
CHALLENGE_SIGNING_SECRET=випадковий_рядок_мінімум_32_символи
```

## 3. Як економиться безкоштовна квота

1. **Локальний пре-чек (`src/lib/challenge-precheck.ts`):** порожній код, незмінений шаблон, звичайний текст замість коду та точний збіг з еталоном перевіряються миттєво без запиту до Gemini.
2. **Серверний кеш (SHA-256):** однакові рішення різних студентів беруться з кешу без повторного звернення до API та без списання квоти.
3. **Анти-спам обмеження:** діє ліміт запитів на хвилину (`6 req/min`) та денний ліміт на користувача (`AI_DAILY_LIMIT_STUDENT`), прив'язаний до верифікованого Firebase ID Token.

## 4. Деплой на окремий хостинг

Оскільки серверні маршрути знаходяться в `src/app/api/*`, проєкт готовий до деплою на будь-який Node.js або Serverless-хостинг:
- **Vercel / Netlify / Firebase App Hosting / Railway / VPS (`npm run build && npm run start`)** — просто додайте змінні з `.env.example` (разом із `GEMINI_API_KEY`) в налаштування Environment Variables.
